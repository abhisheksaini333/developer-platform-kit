# Developer Platform Kit

A developer portal for discovering service ownership, creating tested services, and understanding deployment readiness.

The platform uses Backstage, Node/TypeScript, ASP.NET Core, Keycloak and Argo CD. Service templates produce source, tests, API contracts and deployment configuration together.

## Development

Use Node 16 and run `npm test` for the platform's focused behavior checks. Setup and integration commands are documented as the platform modules are introduced.
